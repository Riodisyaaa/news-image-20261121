A dense newspaper front page summing up Saturday 21 November 2026 in one image: 32 stories across 6 continents, from the GTA 6 launch week to climate talks, markets, AI, science and sport.

Entry for the make.fun bounty: https://make.fun/bounty/news-image-20261121

## Files

- `entry.png` — the front page, 1024×1024
- `index.html` — the page source (inline CSS/SVG, no external resources)
- `main.ts` — copies `entry.png` to the grader's output directory

## Build

Render `index.html` at 1024×1024 (e.g. with a headless browser) into `entry.png`, then run `main.ts` with Node 22.
